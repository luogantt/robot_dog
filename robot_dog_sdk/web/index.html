操控

拖动摇杆
左右 = 转向　上下 = 前后

⚠️ 必须按住不放才会动，松手立即停。 点一下几乎没反应 —— 指令需要约 0.2 秒才爬出轴指令的死区。
键盘：W/S 前后、A/D 转向、Q/E 平移、空格急停。

速度上限

0.15 相对满速的比例

⚠️ 滑条拉到 1.00。
实测这台机器狗在低值区不响应、而且非单调：X=0.06 能走 0.127 m/s，但 0.12 只有 0.027、0.5 只有 0.017； 转向则 0.5/0.8 几乎不转、只有 1.0 能转 180°/2s。 滑条留在低位会表现为"点了没反应"。
（滑条上限由服务端 --max-scale 决定；起步值由 --scale 决定）
