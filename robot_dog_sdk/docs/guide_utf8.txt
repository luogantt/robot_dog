1 本体监控协议

1.1 协议总则

本协议基于TCP或UDP协议（根据具体开发需要进行选择），适用于机器人本体与上位机
（外部板卡或系统）通信使用。

1.1.1 协议层次

本协议在OSI七层体系中所属位置以及协议栈数据结构，如下表所示：

本协议                    应用层（第7层）
TCP/IP协议或UDP/IP协议      传输层（第4层）
                       网络层（第3层）

                       3 / 64
以太网          链路层（第2层）
注： 第5，第6层未用  物理层（第1层）

1.1.2 协议端口号

本协议使用时，机器人本体为TCP/UDP服务端，外部板卡或系统为TCP/UDP客户端。DTLS
服务端（UDP + 加密）地址与端口为 10.21.33.103:30004 ，TLS 服务端（TCP + 加密）
地址与端口为 10.21.33.103:30003 。默认情况下，端口通信启用加密；用户可通过修改 r
obotserve 配置文件关闭加密（需联系技术支持），且系统更新不会覆盖该配置文件。

1.1.3 交互机制

如下图所示，本协议主要使用请求/响应机制。上位机可主动向机器人本体发起数据或状态查
询请求，机器人本体通过响应回复部分请求。

1.1.4 应用协议数据单元

本协议APDU（应用协议数据单元）采用“协议头部+ASDU（应用服务数据单元）”结构，每
个APDU可以携带1个ASDU。

1.1.5 协议头部结构

协议头部长度固定16字节，内容如下表所示。

 序号 内容 长度 值 备注

Command                     消息命令码
            报文发送时间，本地时区，格式：YYYY-MM-DD
   Time                  消息所携带的参数项
   Items

1.3 状态类ASDU消息集
