# S10 决赛代码项目说明

## 1. 已落地的工程结构

```text
src/
├── drdds/                  # S10 消息，已有
├── S10_sdk_deploy/         # RL 底盘控制，已加入 /STEER watchdog
├── dual_airy_merger/       # 双雷达显示/感知合并，禁止作为 LIO 输入
├── s10_sensor_adapter/     # 前 Airy IMU 坐标适配
├── s10_route_nav/          # 路线、避障、健康门控和指令仲裁
└── s10_nav_bringup/        # 建图、示教和比赛 launch/config/script
```

交付目录已经把 Lightning、rslidar_sdk 和 rslidar_msg 放在 `src/` 中。从本目录执行
`colcon build` 即可发现全部必需包，不依赖外层工程中的 `upstream_repos`。

全新 AGX 工作区也可以使用：

```bash
vcs import src < s10_final.repos
git -C src/rslidar_sdk submodule update --init --recursive
src/s10_nav_bringup/scripts/apply_upstream_patches.sh
```

导入后必须重新应用 `UPSTREAM_VERSIONS.md` 中记录的 rslidar 和 Lightning 补丁。

## 2. 节点职责

| 节点 | 作用 | 失效行为 |
|---|---|---|
| `s10_imu_adapter` | 将前 Airy IMU 旋转到 `lidar_link`，禁用无效 orientation | `/IMU` 停止，健康门控失败 |
| `s10_route_recorder` | 定位地图中示教路线和标记检查点 | 不参与正式控制 |
| `s10_route_follower` | Pure Pursuit、检查点、路线走廊 | 发布零速度并置 route fault |
| `s10_obstacle_guard` | 双点云 ROI、减速、停车、受限绕行 | 点云超时输出 STOP |
| `s10_health_monitor` | 数据新鲜度、XYZIRT 字段、位姿跳变 | `/s10_nav/healthy=false` |
| `s10_command_mux` | 唯一 `/STEER` 发布者、限幅、斜率和仲裁 | 立即零指令并取消 enable |
| `rl_deploy` | S10 RL 底盘控制 | 300 ms 未收到 `/STEER` 自动清零 |

## 3. 控制状态

启动 launch 后机器人不会自动运动。控制链必须同时满足：

```text
health=true
AND operator enabled
AND tracking command fresh
AND no emergency latch
AND obstacle state != STOP
AND route not finished/faulted
```

任一条件失效都输出零指令。健康恢复后也不会自动继续，必须由操作员显式重新启用。

## 4. 构建前准备

在 Ubuntu 24.04 + ROS 2 Jazzy 的 AGX 上安装常规依赖：

```bash
sudo apt update
sudo apt install -y \
  python3-colcon-common-extensions python3-vcstool python3-yaml python3-numpy \
  ros-jazzy-diagnostic-msgs ros-jazzy-nav-msgs ros-jazzy-sensor-msgs \
  ros-jazzy-geometry-msgs ros-jazzy-std-srvs
```

Lightning 还需要 PCL、OpenCV、Eigen、glog、gflags、yaml-cpp、TBB、Pangolin 和
OpenGL。正式 AGX 应保存一份已经构建成功的 `install/` 和系统依赖清单，不在比赛
当天临时联网构建。

## 5. 构建

```bash
source /opt/ros/jazzy/setup.bash
cd /home/nvidia/goai_ws
colcon build --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Release
source install/setup.bash
```

如果当前目录不是 `/home/nvidia/goai_ws`，需要同步修改脚本和两个 Lightning YAML
中的绝对路径。

## 6. 建图与示教

编辑 `src/s10_nav_bringup/config/s10_lightning_slam.yaml` 的 `system.map_path` 后：

```bash
ros2 launch s10_nav_bringup mapping.launch.py
```

人工遥控完成建图和闭环，停止时 Lightning 会保存地图。随后编辑定位配置的地图和
初始位姿，再运行：

```bash
ros2 launch s10_nav_bringup record_route.launch.py \
  output_file:=/home/nvidia/goai_data/routes/final_route_v01.yaml
```

示教服务：

```bash
ros2 service call /s10_route_recorder/set_recording std_srvs/srv/SetBool '{data: true}'
ros2 service call /s10_route_recorder/mark_checkpoint std_srvs/srv/Trigger '{}'
ros2 service call /s10_route_recorder/set_recording std_srvs/srv/SetBool '{data: false}'
ros2 service call /s10_route_recorder/save std_srvs/srv/Trigger '{}'
```

每个计分点现场停稳后调用一次 `mark_checkpoint`。

## 7. 正式导航

```bash
ros2 launch s10_nav_bringup navigation.launch.py \
  route_file:=/home/nvidia/goai_data/routes/final_route_v01.yaml
```

确认：

```bash
ros2 topic echo /s10_nav/healthy
ros2 topic echo /s10_nav/diagnostics
ros2 topic info /STEER --verbose
```

`/STEER` 应只有 `s10_command_mux` 一个导航发布者。手柄完成站立和进入 RL 模式后，
在空旷低速测试条件下启用：

```bash
ros2 service call /s10_nav/set_enabled std_srvs/srv/SetBool '{data: true}'
```

急停：

```bash
ros2 service call /s10_nav/emergency_stop std_srvs/srv/Trigger '{}'
```
